# S1.1：Story Scene Card 扩展

Scene Card 是 Story-owned 的候选编辑层，不属于 Person Sketch，也不写入
Relation。它解释“这一则故事里的这一幕”，而人物关系卡仍只显示已审阅的
Person ↔ Person 事实。

## 字段纪律

- 时间继续使用 `exact` / `range` / `approximate` / `unknown`；9 则当前都没有足够项目内出生年和故事年输入，年龄保持 `unknown`。
- 地点只保留来源支持的名称：新亭、瀨乡、上虞；不做地理编码或现代行政区推断。
- `present`、`referenced_in_context` 等场景角色是逐则候选判断；Mention、PersonStoryLink 和同场共现都不自动等于在场。
- 未物化人物（如王坦之、郗超、支道林、孙兴公、桓子野、许玄度）保留为来源人物，只读不可导航，不创建 Person。
- 状态、位置和背景短文本均保留 Evidence、`assertion_status` 与 `review_status`；刘注报告不被扁平成正文直接事实。
- Scene positional context 只解释本则中的位置，不建立或修改 `data/annotation/wp1-relations.json`。

## 关键读法

`06-yaliang-029` 的卡片把简文帝晏驾后的遗诏、桓温的疑虑、新亭陈兵召见和谢安的应对
分开显示；它帮助读者理解三人为何出现在同一幕，但不声称桓温与谢安因此已有新的
长期 Relation。其他卡片同样只呈现故事拥有的场景信息。
