# Milestone 1 scope

Milestone 1 proves the smallest useful static reading path:

```text
Story → Person → Relation → Related Story → Era
```

The target scope is:

| Area | Target | Current status |
|---|---:|---|
| Core people | 6 | carried forward from the existing six-person pilot |
| Stories | 15–30 | candidate set not yet frozen |
| Eras / motifs | at least 1 | `era-001` is a candidate based on `雅量` |
| Validated first story | 1 | `06-yaliang-019` |

The six existing person IDs are retained as compatibility IDs:

```text
wang-xizhi
xi-jian
wang-dao
wang-ningzhi
xie-daoyun
xie-an
```

They are not renamed in WP1. New IDs created after this baseline should use
assigned opaque identifiers and must not be generated from names, titles,
URLs, or generated prose.

The first story is the reviewed canonical entry `06-yaliang-019`, commonly
labelled `东床坦腹`. Its source text is generated from the existing canonical
entry at:

`content/processed/shishuo/entries/06-yaliang/entry-019.md`

The final 15–30 story selection, final Era set, and the complete set of
reviewed Person Sketch material remain `candidate` / `TODO` until explicitly
reviewed. WP1 does not invent those selections.

The machine-readable scope manifest is
`data/manifest/milestone-1.json`.
