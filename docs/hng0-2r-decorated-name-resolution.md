# HNG0.2R — Decorated Historical Surface Resolution

HNG0.2R is an additive, offline repair projection over the frozen HNG0.1
candidate layer. HNG0.2 remains the baseline and is not regenerated by this
stage.

The resolver first retains the existing exact, alias, courtesy-name, title,
kinship-context, and biography-local rules. The new generic stage then looks
for the longest unique canonical Person name of at least two characters at the
end of a source surface. It requires the complete decorated surface to occur
in the same supplied evidence passage. A unique split is recorded as
`decorated_name_suffix` with medium confidence; ties, implausible one-character
splits, and temporal conflicts remain unresolved or ambiguous.

The prefix is retained verbatim and classified only when the visible surface
supports a conservative class such as `geographic`, `office`, `title`,
`nobility`, or `kinship-role`. This is lookup metadata, not a correction to
the source text. A surface that cannot be resolved remains an HNG-only
provisional identity where the existing HNG rules allow one; no canonical
Person is created.

HNG0.2R writes to `data/generated/hng0-2r/` and records the HNG0.2 artifact
hashes and resolver source hash. It is evidence infrastructure only and never
writes canonical Persons, Relations, Facts, or Events.
