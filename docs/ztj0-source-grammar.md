# ZTJ0：实际 Kanripo 语法观察

本报告来自实际获取的 revision，而不是由《世说》或《三国志》的语法推测。

## KR2b0007（通鑑主来源）

- 仓库：`https://github.com/kanripo/KR2b0007.git`
- revision：`80174f61e491db29f9921d0d3e54a59649419aa9`
- 文件：`KR2b0007_000.txt` 至 `KR2b0007_295.txt`，共 296 个文本容器。
- `_000` 是提要和进书表；`_001` 至 `_294` 对应卷一至卷二百九十四；
  `_295` 是带有 `卷二百九十5` 的异常短 stub，锁定但不当作卷二百九十五。
- 文件头使用 Org/Emacs 形式的 `#+TITLE`、`#+DATE`、`#+PROPERTY`；实际观察到
  `ID`、`BASEEDITION`、`JUAN`。主来源没有用 `FILE` 指令提供卷边界。
- 物理行以 `¶` 结束。页码形如
  `<pb:KR2b0007_WYG_069-1a>`，包含 witness、文件号和页/面坐标。
- 每个主卷的头部实际出现 `資治通鑑卷...`、`宋司馬光撰`、`胡三省音註`，
  随后是 `周紀`、`秦紀`、`漢紀`、`魏紀`、`晉紀` 等纪标题。
- 主要正文与胡注以平衡、最大深度为一的圆括号交错。当前 294 个主卷均可用
  这一边界保守分层；注层被标为 `胡三省`，正文被标为 `司馬光`。
- 卷一百二实际写作 `晉記二十四`，而多数同族标题写 `晉紀`。处理器保留
  原表面，并把 `紀/記` 都视为观测到的纪标题；没有把它改成规范字。

## KR2b0008（考異）

- 仓库 revision：`624ef729c4c4945bc3b4e0b1e382e49215957974`。
- 文件为 `KR2b0008_001.txt` 至 `_030.txt`，属性 `JUAN 1` 至 `30`，页码使用
  `KR2b0008_SBCK_...`。
- 它也使用 `¶`、`<pb:...>` 和圆括号，但圆括号在这里可能是考异引文、校勘
  论证的一部分。ZTJ0 因而将每卷完整正文保留为一个考异证据 block，不把括号
  猜成胡三省层，也不拆出“某来源胜出”的自动决定。

## KR2b0010（目錄）

- 仓库 revision：`c730f25e3124442a40ae86c737f19d83b84a76a3`。
- 获取到 `KR2b0010_000.txt` 和 26 个编号文件；README 的目录列出三十卷，
  但实际文件编号本身存在跳号，且许多页只有 `¶` 与页码标记。
- 页码使用 `KR2b0010_WYG_...`。ZTJ0 保留这些页坐标，按每个文件记录文字量，
  将稀疏文件如实标为 `sparse_or_page_marker_only`，不 OCR。

## 解析原则

处理器 `scripts/build_ztj0_corpus.py` 只做结构性工作：源文件先按 UTF-8 原字节
计算 SHA-256，再在处理记录中保留完整 `source_text`；便利文本只移除 `¶` 与页码
标记。每个 block 和胡注都有字符、行号、页码坐标。无法可靠分层时的策略是保留
交错文本并标记 unresolved，而不是猜测作者层。
