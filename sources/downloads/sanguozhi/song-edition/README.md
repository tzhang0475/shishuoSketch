# 南宋刊本《三國志》 download area

Payloads in this directory are intentionally ignored by Git. The downloader
resolves the target filename from the Internet Archive `songkeben` metadata
record and prefers the searchable/text PDF plus OCR text. It deliberately
does not download the much larger JP2 ZIP unless a future explicit archival
option is added.

Page images remain the textual verification authority. OCR is only a
convenience derivative for search and alignment.
