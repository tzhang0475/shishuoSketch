# 《三國志》 Wikisource machine witness

This directory stores the locally retrieved, provenance-locked Wikisource
machine witness used by SGZ1. Raw API JSON and raw returned wikitext are
ignored by Git. The tracked lock and metadata record page titles, revisions,
coordinates, sizes, and SHA-256 values.

The witness covers `三國志/卷01` through `三國志/卷65`. It is complete
machine-text evidence infrastructure, not a replacement for the Kanripo/WYG
魏書 witness and not a source of canonical historical facts by itself.
