# 晉書斠注 download area

Payloads in `pdf/` and `ocr/` are intentionally ignored by Git. They are
recreated by `python scripts/download_witnesses.py --jinshu-jiaozhu` from
Internet Archive metadata. The lock manifest records each accepted volume,
selected filename, source URL, size, SHA-256, and retrieval timestamp.

OCR is a non-authoritative search/alignment derivative; scanned PDF pages are
the textual verification evidence.
